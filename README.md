# اردکِ اسکیت‌باز (Duck Skate)

بازی دوبعدی اسکیت‌سواری با شخصیت‌های نقاشی‌شده روی کاغذ کرافت — HTML5 Canvas + JavaScript خالص، بدون کتابخانه، سرور، کلید API یا سرویس پولی.

## اجرای محلی

**ساده‌ترین روش:** فایل `index.html` را با دوبار کلیک در Chrome / Edge / Firefox / Safari باز کنید. همه تصاویر داخل `src/assets-data.js` جاسازی شده‌اند، پس بدون سرور هم کار می‌کند (فروشگاه رنگ هم).

**با سرور محلی (برای تست روی موبایل در شبکه خانگی):**
```bash
cd duck-skate
python3 -m http.server 8000
# دسکتاپ:  http://localhost:8000
# موبایل:  http://<IP-کامپیوتر>:8000
```
**انتشار:** کل پوشه را روی GitHub Pages / Netlify آپلود کنید؛ فایل ورودی `index.html` است.

> فونت وزیرمتن از Google Fonts بارگذاری می‌شود؛ اگر اینترنت نباشد، فونت سیستم (Tahoma) جایگزین می‌شود.

## کنترل‌ها
| دسکتاپ | موبایل | کار |
|---|---|---|
| Space / ↑ / W | دکمه «پرش» یا ضربه روی صفحه | پرش (نگه داشتن = بلندتر) |
| ↓ / S | ▼ | روی زمین: خم شدن/سُرخوردن — در هوا: چرخش نمایشی (+۳۰) |
| → / ← | ▶ / ◀ | تندتر / آهسته‌تر — در قلمرو خرس: جابه‌جایی |
| P / Esc | دکمه ❚❚ | توقف |

## ساختار پروژه
```

src/sprites.js        بارگذاری شخصیت‌ها، رنگ‌های فروشگاه (تغییر Hue) و رسم
src/draw.js           ابزار رسم «مداد رنگی روی کرافت» و وسایل صحنه (مخروط، جعبه، درخت…)
src/levels.js         تعریف ۴ مرحله با سازنده زمین (flat / slope / kicker / gap)

src/game.js           حلقه بازی، برخوردها، دوربین، رندر، ذخیره LocalStorage

src/main.js           راه‌اندازی
assets/characters/    PNG شفاف شخصیت‌ها (استخراج‌شده از نقاشی‌های شما)
assets/backgrounds/   بافت کاغذ کرافت بی‌درز
tools/                اسکریپت‌های پایتون برای آماده‌سازی تصاویر
```

## نقش شخصیت‌ها
- **اردک اسکیت‌سوار:** قهرمان قابل کنترل.
- **حلزون:** مانع آهسته؛ بپر یا روی سرش فرود بیا (گیج می‌شود).
- **قورباغه‌ها:** مانع ثابت، یا جفت پرنده که بالا و پایین می‌پرند (وقتی بالا هستند از زیرشان رد شو).
- **روح کلاه‌دار:** شناور بالا/پایین؛ **روح طلایی درخشان** مهربان است و تو را به مسیر سکه‌های مخفی آسمان پرتاب می‌کند.
- **سگ:** نقطه امن؛ یک قلب می‌دهد (اگر قلب‌ها پر باشد ۱۰۰ امتیاز).
- **لیوانی:** نگهبان؛ در محدوده‌ای جابه‌جا می‌شود و قطره پرتاب می‌کند؛ با پرش روی لبه‌اش ساکت می‌شود.
- **کرم کلاه‌دار:** کش می‌آید و کوتاه می‌شود؛ وقتی کوتاه است بپر. کلاهش ترامپولین است.
- **خرس:** باس نهایی با ۵ جان و ۳ فاز (سریع‌تر شدن حمله‌ها). بعد از حمله شارژی به دیوار می‌خورد و گیج می‌شود — آن موقع روی سرش فرود بیا.

## مراحل
1. **پارک اسکیت** — آموزش پرش، خم شدن، نیمکت و میله، سکه.
2. **مسیر جنگلی** — شیب، چاله، شاخه پایین، حلزون، افزایش سرعت + نقطه ذخیره.
3. **چالش شخصیت‌ها** — روح، روح طلایی، قورباغه‌ها، سگ، لیوانی، کرم + دو نقطه ذخیره.
4. **قلمرو خرس** — مسیر کوتاه و نبرد. در صورت باخت، «دوباره» مستقیم از ابتدای نبرد شروع می‌کند.

## فروشگاه رنگ‌ها
سکه‌های جمع‌شده (هر ستاره = ۱۰ سکه) بعد از هر تلاش به کیف پول اضافه می‌شوند. برای هر ۸ شخصیت ۸ رنگ وجود دارد (رنگ اصلی رایگان). رنگ‌ها با چرخش Hue روی پیکسل‌های رنگی ساخته می‌شوند و خطوط مشکی دست‌کشیده دست‌نخورده می‌مانند. انتخاب‌ها، سکه‌ها، مراحل باز‌شده و بهترین امتیاز در LocalStorage ذخیره می‌شوند.

## جایگزینی تصاویر شخصیت‌ها
1. تصویر جدید را با **همان نام** در `assets/characters/` بگذارید:
   `duck.png, ghost.png, bear.png, dog.png, snail.png, frogs.png, glass.png, worm.png`
   - PNG با پس‌زمینه شفاف، برش‌خورده دور شخصیت، حدود ۳۰۰–۴۰۰ پیکسل.
   - پایین تصویر = جای پا/زمین شخصیت.
2. اجرا کنید: `python3 tools/build_assets.py` (فایل `src/assets-data.js` دوباره ساخته می‌شود).
3. اگر اندازه نمایش باید عوض شود، مقدار `h` همان شخصیت را در `G.CHARS` داخل `src/sprites.js` تغییر دهید. (`flip: true` یعنی تصویر آینه‌ای رسم شود تا رو به بازیکن باشد.)

**اگر عکس با پس‌زمینه کاغذی دارید:** با `tools/extract_sprites.py` پس‌زمینه را حذف کنید:
```bash
pip install pillow numpy scipy
python3 tools/extract_sprites.py <پوشه-عکس‌ها> assets/characters
python3 tools/build_assets.py
```
نام فایل‌ها و کادر برش هر شخصیت در دیکشنری `JOBS` همان اسکریپت تعریف شده است. اگر خط دور یک نقاشی شکاف داشت، با `SEALS` آن را ببندید.
بافت کاغذ با `tools/make_paper.py` ساخته می‌شود.

اگر تصویری پیدا نشود، بازی خراب نمی‌شود و یک شکل موقت جایگزین رسم می‌کند.

## چک‌لیست تست
- [ ] بازی بدون خطا در کنسول باز می‌شود و منو نمایش داده می‌شود.
- [ ] «شروع بازی» مرحله ۱ را شروع می‌کند؛ پیام‌های آموزشی ظاهر می‌شوند.
- [ ] پرش کوتاه (ضربه) و بلند (نگه‌داشتن) فرق دارند؛ فرود روی زمین، رمپ، نیمکت و میله درست است.
- [ ] ↓ روی زمین از زیر تابلو/شاخه/میله عبور می‌دهد؛ ↓ در هوا چرخش می‌زند و بعد از فرود +۳۰ می‌دهد.
- [ ] برخورد با مخروط/جعبه/شخصیت یک قلب کم می‌کند و بازیکن مدت کوتاهی چشمک‌زن و آسیب‌ناپذیر است.
- [ ] افتادن در چاله یک قلب کم می‌کند و بازیکن قبل از چاله برمی‌گردد.
- [ ] هر سکه فقط یک بار شمرده می‌شود؛ ستاره ۱۰ سکه و ۱۰۰ امتیاز می‌دهد.
- [ ] پرش روی حلزون/قورباغه/لیوانی آن‌ها را گیج می‌کند؛ کلاه کرم بازیکن را پرتاب می‌کند؛ روح طلایی پرتاب بلند می‌دهد.
- [ ] سگ قلب اضافه می‌کند؛ نقطه ذخیره پیام می‌دهد و بعد از باخت «دوباره» از آن‌جا شروع می‌شود.
- [ ] توقف (دکمه/P/Esc) بازی را متوقف و «ادامه» آن را از همان نقطه ادامه می‌دهد؛ «شروع دوباره» همه‌چیز را از اول مرحله می‌سازد.
- [ ] رسیدن به پرچم: صفحه پیروزی، جایزه قلب‌ها، باز شدن مرحله بعد.
- [ ] نبرد خرس: نوار سلامت خرس، علامت «!» قبل از هر حمله، موج زمینی، عسل، حمله شارژی، گیجی و آسیب با پرش روی سر؛ ۵ ضربه = پیروزی و صفحه «قهرمان شدی».
- [ ] باخت در نبرد → «دوباره» مستقیم نبرد را شروع می‌کند.
- [ ] فروشگاه: خرید با سکه کافی، پیام کمبود سکه، انتخاب رنگ خریده‌شده، اعمال رنگ در بازی و منو.
- [ ] بعد از رفرش: سکه‌ها، رنگ‌ها، مراحل باز و بهترین امتیاز باقی می‌مانند.
- [ ] موبایل عمودی و افقی: دکمه‌های لمسی کار می‌کنند، صفحه اسکرول نمی‌شود، چرخاندن گوشی چیدمان را خراب نمی‌کند.
- [ ] دکمه صدا همه صداها را قطع/وصل می‌کند.

### تست خودکار انجام‌شده
با Playwright (Chromium) این موارد بررسی شد: اجرای بدون خطا؛ عبور ربات خودکار از مرحله ۱ بدون هیچ آسیب و تمام شدن مراحل ۲ و ۳؛ شکست خرس با ۵ پرش در حالت گیجی و نمایش صفحه پایان؛ خرید/انتخاب رنگ؛ توقف/ادامه؛ مرگ و شروع دوباره؛ شروع دوباره از نقطه ذخیره؛ کنترل لمسی در نمای عمودی ۳۹۰×۸۴۴ و افقی ۸۴۴×۳۹۰.
افزودن `?god` به آدرس، بازیکن را آسیب‌ناپذیر می‌کند (فقط برای تست).
